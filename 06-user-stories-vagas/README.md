| [test-cases.md](test-cases.md) | 23 casos de teste, cada um ligado a um critério de aceite, com prioridade |

**Habilidades:** personas, user stories (formato *As a… I want… so that…*), critérios de aceite, derivação de casos de teste a partir de ACs, priorização.
