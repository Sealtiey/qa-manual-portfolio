# User stories — Vagas.com

Seis user stories com critérios de aceite para duas features propostas a partir das personas: **Personalized Technical Test** e **Smart Talent Pool**. Conteúdo original em inglês.

## Feature 1: Personalized Technical Test

### User Story 1: Test Selection

As a candidate, I want to choose a technical test related to my field so that I can demonstrate my skills before applying for a job.

**Acceptance Criteria:**

- The candidate can view a list of available tests based on their field of expertise.

- The candidate can select a test and start when ready.

- The system displays a time limit for completing the test.

- The test is available only for registered candidates.

### User Story 2: Test Evaluation

As a candidate, I want to receive a performance report on the technical test so that I can understand my strengths and areas for improvement.

**Acceptance Criteria:**

- After completing the test, the system generates a detailed report with scores and feedback.

- The report highlights correct and incorrect answers along with improvement suggestions.

- The candidate can access the report in the “My Tests” section.

- The system allows the candidate to retake the test after a specific period to improve their score.

### User Story 3: Employer Validation

As a recruiter, I want to see candidates’ technical test results so that I can evaluate their skills before scheduling interviews.

**Acceptance Criteria:**

- The recruiter can view test results in the candidate’s profile.

- The system displays the candidate’s score and proficiency level.

- The recruiter can filter candidates who have taken a relevant technical test for the job opening.

## Feature 2: Smart Talent Pool

### User Story 4: Talent Pool Registration

As a candidate, I want to opt into the Talent Pool so that companies can find me even if I haven’t applied for a specific job.

**Acceptance Criteria:**

- The candidate can enable or disable participation in the Talent Pool.

- The candidate’s profile must be updated to be included in the Talent Pool.

- The system notifies the candidate when a company views their profile.

### User Story 5: Intelligent Candidate Search

As a recruiter, I want to access a talent pool filtered by skills and experience so that I can quickly find qualified candidates.

**Acceptance Criteria:**

- The recruiter can search for candidates using keywords, skills, and experience.

- The system suggests candidates who match an open position.

- The suggested profiles include relevant information, such as completed technical tests and availability.

- The recruiter can save interesting profiles for future opportunities.

### User Story 6: Job Opportunity Notifications

As a candidate, I want to receive notifications when a job that matches my profile is posted so that I can increase my chances of getting hired.

**Acceptance Criteria:**

- The candidate receives notifications via email or on the platform about new relevant job openings.

- The candidate can adjust their notification preferences.

- The system recommends jobs based on the candidate’s profile and completed technical tests.
