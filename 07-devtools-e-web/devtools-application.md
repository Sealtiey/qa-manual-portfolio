# DevTools — Application (cookies)

Leitura dos cookies de sessão de uma aplicação web na aba *Application → Cookies*, para entender como a autenticação é mantida no navegador.

| Cookie name | Cookie value |
|---|---|
| token | `<token>` (JWT — valor removido) |
| Expires | 2026-07-27T15:15:55.641Z |
| userName | `<username>` |
| userID | `<uuid>` |

> Os valores reais foram removidos: o JWT de sessão continha credenciais da conta de teste no payload — um bom exemplo de por que tokens não devem ser compartilhados (e de que dados sensíveis não deveriam ir no payload de um JWT).
